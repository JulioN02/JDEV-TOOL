JDEV — un solo binario, 10 utilidades para tu día a día

Genera UUIDs, valida JSON, codifica base64, convierte timestamps, calcula hashes, hashea contraseñas con bcrypt, decodifica JWT (solo lectura), procesa CSV y prueba APIs — todo bajo un solo comando jdev, con dos formas de uso (terminal directa y TUI interactivo) y mensajes en español o inglés.

01 ¿Qué es JDEV?

Un kit de herramientas de desarrollo en línea de comandos: diez utilidades de trabajo diario bajo un solo binario. La idea no es reemplazar a programas grandes (curl, jq, openssl…), sino concentrar las tareas repetidas del día a día en un único contrato de texto, estable y componible.

Cada utilidad es un programa pequeño que hace una cosa bien y se encadena con los demás mediante pipes: jdev csv tojson | jq. Es la filosofía Unix aplicada a un toolkit de desarrollo moderno.

GUI

Amigable y visual, ideal para explorar.

Costo: no automatizable, no componible desde un script.

Librería

Reutilizable dentro de código.

Costo: el usuario final no la usa; hay que escribir el programa alrededor.

CLI

Automatizable (scripts / CI), componible (pipes), universal.

Costo: exige respetar un contrato de texto y códigos de salida estables.

Las utilidades de jdev las usa un humano y un script → el CLI es la única forma que sirve para ambos.

02 Las 10 utilidades

Nueve módulos de datos y un TUI que los envuelve. Todos comparten el mismo contrato: datos al stdout, errores al stderr y códigos de salida estables.

uuidRFC 4122 · RFC 9562

UUID v4 aleatorios (criptográfico) y v7 ordenados por tiempo, en cualquier cantidad, uno por línea.

$ jdev uuid --v7 --count 3
jsonformat · minify · validate

Formatea, minifica y valida JSON con la posición exacta del error (línea y columna).

$ echo '{"a":1}' | jdev json format
base64RFC 4648

Codifica y decodifica base64 estándar y URL-safe (la variante de JWT y query params).

$ echo -n "hola" | jdev base64 encode --url
timestampepoch ↔ ISO 8601

Convierte entre segundos/milisegundos Unix y fechas legibles UTC o con offset local.

$ jdev timestamp 1710000000 --iso
hashsha256 · sha512 streaming

Huella digital de archivos o stdin en streaming: memoria fija aunque el archivo pese gigas.

$ echo -n "texto" | jdev hash
passwordbcrypt · timing-safe

Genera, hashea y verifica contraseñas con bcrypt, guard de 72 bytes y verificación timing-safe.

$ jdev password hash "misecreto"
jwtsolo lectura

Decodifica header y payload de un token JWT como JSON legible. La firma nunca se toca.

$ jdev jwt "eyJhbGciOi..."
csvRFC 4180 streaming

Inspecciona, normaliza (BOM, CRLF) y convierte CSV a JSON con un parser estricto en streaming.

$ jdev csv tojson export.csv
httpmini-curl · secrets enmascarados

Peticiones HTTP mostrando status + cabeceras + cuerpo, con authorization, cookie y set-cookie siempre como ***.

$ jdev http -H "Authorization: Bearer x" URL
tuimenú interactivo · es/en

Un menú en pantalla completa que envuelve los 9 módulos, con modo libre e idioma en caliente.

$ jdev tui

04 Diseño de ingeniería

Lo que hace que jdev sea confiable para scripting: un contrato de errores explícito, disciplina de pipes y seguridad por diseño.

Contrato de exit codes

CódigoSignificadoEjemplo real
0 Éxito — dato o veredicto en stdout jdev uuid, jdev json validate, HTTP aunque sea 404
1 Error de uso — el comando está mal escrito flag inválido, opciones excluyentes, TUI sin TTY
2 Error de ejecución — la operación falló archivo no existe, JSON inválido, bcrypt malformado, timeout de red

Cada error lleva un code estable (INVALID_JSON, IO_READ, BCRYPT_LENGTH_EXCEEDED, TIMEOUT, TLS…) para que un script distinga tipos sin parsear texto.

Pipes y determinismo
$ echo '{"a":1}' | jdev json validate
valid JSON
echo $? → 0
$ jdev uuid --v4 --v7
--v4 and --v7 are mutually exclusive
echo $? → 1
$ jdev json validate archivo-inexistente.txt
cannot read file 'archivo-inexistente.txt': ENOENT…
echo $? → 2
Seguridad por diseño
$ jdev http http://127.0.0.1:8787/set-cookie
HTTP/1.1 200 OK
content-type: application/json; charset=utf-8
set-cookie: ***
set-cookie: ***
{"ok":true}
$ echo -n "texto" | jdev hash
f46e3b17a6b639e5efddc3d1498ad73491599c22220f7ef6e14772f4ee25b913
SHA-256 · 64 hex (32 bytes)

Garantías

  • ✓Contraseñas. BCRYPT con sal y costo configurable, verificación timing-safe, guard de 72 bytes medido en bytes UTF-8 aplicado antes de que bcrypt trunque en silencio.
  • ✓Aleatoriedad. Siempre randomBytes criptográfico, nunca Math.random.
  • ✓JWT. La firma jamás se decodifica ni se imprime; los errores no repiten el token.
  • ✓HTTP. Cabeceras authorization / cookie / set-cookie siempre como ***; --insecure es scoped a esa request (un Agent de undici por llamada, nunca un dispatcher global).
  • ✓Pipes. Datos al stdout, errores al stderr; sin color en pipes por defecto; EPIPE silencioso (jdev uuid | head -1 no rompe el pipeline).
  • ✓Streaming. HASH y CSV procesan por chunks/filas: memoria acotada aunque el archivo pese gigas.

06 Instalación y puesta en marcha

Dos vías de acceso, ninguna configuración previa. Requisito único: Node.js ≥ 22.12.0.

1

Desde npm (recomendado)

Instala el binario global jdev y queda listo para usar.

# npm
npm install -g @jsoftsolutions/jdev
2

Desde GitHub (código fuente)

Clona el repositorio, instala dependencias y usa la opción A o B.

# clonar e instalar
git clone https://github.com/JulioN02/JDEV-TOOL.git
cd JDEV-TOOL
npm install

# opción A: construir el binario
npm run build && npm link

# opción B: ejecutar directo desde TypeScript (node ≥ 22.12)
node src/index.ts --version
3

Verificación

Confirma la versión y la lista de los 10 subcomandos.

jdev --version   # 0.13.1
jdev --help      # lista los 10 subcomandos
4

Variables de entorno útiles

JDEV_LANG=es|en fuerza el idioma, NO_COLOR=1 desactiva colores y FORCE_COLOR=1 los fuerza incluso en pipes.

07 Conclusión

JDEV es un kit de utilidades CLI con ingeniería real detrás: un contrato de errores que los scripts pueden consumir, disciplina de pipes, seguridad por diseño en contraseñas, JWT y HTTP, y dos superficies (terminal directa + TUI) sobre el mismo motor.

Verificación realizada en esta revisión: build OK, typecheck OK y 226/226 tests pasando (node:test). Las evidencias de la sección 05 son salidas reales de la versión 0.13.1.

Lección clave

Un CLI de utilidades se vuelve confiable cuando respeta su contrato de texto: salida estable, errores a stderr, códigos de salida significativos y secretos que nunca se imprimen por accidente. Eso es lo que convierte a jdev en algo que un humano puede usar y un script puede automatizar.
